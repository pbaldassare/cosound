# Logic Pro – DAW knowledge

Research date: 2026-11-24. Current version: **Logic Pro for Mac 13.0** (release notes page published
2026-11-06; exact release date not stated) [S1]. The user guide PDF covers Logic Pro 13 [S2].
macOS only.

## Integration routes (ranked for COSOUND)

There is **no public application-level scripting API** for Logic Pro (no AppleScript dictionary,
SDK or project API is documented in the user guide or release notes) [S1][S2]. What exists:

1. **Control-surface protocols (bidirectional)** – Logic ships support profiles for Mackie Control
   (incl. MCU-compatible devices), HUI, and EuCon; communication is bidirectional, so a surface
   receives fader/parameter feedback [S4]. Logic also supports **OSC** devices via Controller
   Assignments: editable OSC message paths, normalized 0.0–1.0 values, UDP over IPv4 only [S2].
   A COSOUND bridge could emulate an MCU over a virtual MIDI port or act as an OSC device to drive
   transport, mixer, plug-in parameters and automation modes (the exact OSC path vocabulary is not
   published as a developer spec → to verify).
2. **Controller Assignments / Learn + key commands** – any MIDI control can be learned onto Logic
   commands and parameters; key commands are assignable and can be triggered by MIDI [S2]. Lua
   scripting is used internally for many keyboard controllers, but Apple does not document it as a
   third-party API [S4] (to verify).
3. **Scripter (JavaScript MIDI FX plug-in)** – official, documented, but runs *inside* a channel
   strip and only processes/generates MIDI events: `HandleMIDI`, Event types (NoteOn/Off,
   ControlChange, PitchBend, ProgramChange, ChannelPressure, PolyPressure), timed sends
   (`sendAtBeat`, `sendAfterBeats`, `sendAfterMilliseconds`) and **TargetEvent**, which can drive a
   *plug-in parameter on the same channel strip* (via "Learn plug-in parameter") [S3]. It cannot
   create tracks, edit the arrangement or read project state [S3].
4. **Intelligent assistant (beta, Logic 13)** – Apple's own natural-language assistant can add/delete
   tracks, set volume/pan/mute/solo, create MIDI regions, edit tempo/key/time signature, add and
   adjust plug-ins, control transport [S2]. It is **internal UI only** (requires Apple Creator Studio
   subscription, Apple silicon, macOS 27+, English only) [S1][S2]; no external API is documented,
   so COSOUND cannot call it (none). Relevant as a competitor/benchmark.
5. **Logic Remote (iPad/iPhone)** – controls playback, recording, patches/plug-ins, mixing and
   automation [S2], but its protocol is private (none for COSOUND).
6. **UI automation** – macOS Accessibility API (AXUIElement) to read/press UI elements [S5], plus
   synthesized key commands. Requires user-granted Accessibility permission; fragile across
   versions.
7. **File interchange** – Standard MIDI file import/export, AAF import/export, Final Cut Pro XML,
   MusicXML export, audio import [S2].

## Feature facts

- **Plug-in formats**: Audio Units only – AUv2 (Components folder) and Audio Unit Extensions (AUv3)
  [S2]. No VST/VST3/AAX/CLAP documented.
- **MIDI**: Standard MIDI file import (File > Import) and export of MIDI regions as SMF (Format 0
  requires joining regions) [S2]. Logic 13 improves MIDI file import (stepped pitch bend, CC order,
  key signatures) and adds MPE support on the Play Surface [S1]. MMC: Logic acts as MMC master (sends
  transport to external machines) [S2].
- **Import**: File > Import > Other handles AAF, supported MIDI, XML and project files [S2].
- **Export / bounce**: export one/all tracks as audio files (one file per track = stems); Bounce in
  Place for tracks/regions; project bounce; AAF export (44.1–96 kHz, WAV/AIFF, 16/24-bit, regions
  with position references and volume automation) [S2].
- **DAWproject**: not mentioned in the user guide or release notes → none (not documented) [S1][S2].
- **Stem separation**: Stem Splitter; Logic 13 can split drums into kit pieces [S1].
- **Automation**: recordable from control surfaces even outside record mode [S4].

## Capability table (what COSOUND can drive from outside)

| Operation | Class | How | Source ID |
|---|---|---|---|
| Create track | ui-automation | Key command / menu via Accessibility; (assistant can, but no external API) | S2, S5 |
| Insert MIDI clip/region | protocol | Import a Standard MIDI file generated by COSOUND; or record MIDI sent over a virtual port | S2 |
| Import audio | ui-automation | File > Import / drag into Tracks area (no API) | S2 |
| Set tempo / key | ui-automation | Control bar / global tracks via UI; tempo can also arrive with an imported MIDI file (to verify) | S2 |
| Transport play/stop/locate | protocol | Mackie Control / HUI / OSC transport, or MIDI-learned key commands | S2, S4 |
| Set fader/pan/mute | protocol | MCU/HUI/EuCon/OSC channel strips (bank-relative, bidirectional) | S2, S4 |
| Insert plugin | ui-automation | Plug-in slot menus via Accessibility (MCU plug-in insertion not confirmed → to verify) | S4, S5 |
| Set plugin parameter | protocol | MCU/OSC parameter pages or Learned controller assignment; Scripter TargetEvent (same strip only) | S3, S4 |
| Write automation | protocol | Move controls via surface/OSC while automation mode is Latch/Touch/Write | S4 |
| Load preset (patch/plug-in setting) | ui-automation | Library/Browser via UI (Logic Remote can, private) | S2 |
| Export / bounce | ui-automation | File > Bounce / Export menus via UI | S2 |
| Read project state | to-verify | Partial via surface feedback (names, levels on MCU/OSC); project file format undocumented | S4 |

## Limitations

- No documented scripting/automation API for project structure (tracks, regions, plug-ins, export).
- Scripter is MIDI-only and confined to its channel strip [S3].
- The built-in assistant has no external interface and needs a paid subscription and macOS 27 [S1].
- Control-surface routes are bank/selection-relative (8-channel pages), not addressable by track ID.
- OSC path catalogue and Lua device-script format are not published as developer specs (to verify).
- AU only: COSOUND's plug-in knowledge for Logic must map to AU parameters [S2].
