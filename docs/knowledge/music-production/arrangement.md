# Structure and arrangement

Verified 2026-11-24. Sources: [sources.md](sources.md).

**Status.** Section names and phrase logic are well documented in practitioner sources (C). The per-genre
bar-timeline templates in §6 are **COSOUND starting templates** assembled from those sources and from the genre
tutorials; they are conventions, not measurements of any real track, and every template is **(to verify)** against
the user's own reference tracks before being presented as "typical".

## 1. Section vocabulary

| Section | Job | Notes / sources |
|---|---|---|
| Intro | Let a DJ mix in; establish groove | Usually drums/percussion plus atmosphere, often no bass in techno [S5]; avoid strongly melodic material at start and end so the track mixes easily [S7] |
| Groove / construction | Stack the core loop | Hats, percussion, bass, then melody enter in stages [S5][S12] |
| Main theme / hook | The identity of the track (lead, chord stab, vocal, bass riff) | Lead entering at bar 17 in NI examples [S8][S11] |
| Breakdown | Remove energy, showcase harmony/melody | Strip kick and bass first; keep hats/shakers for full-energy parts; can sit a few dB lower [S7]; trance requires at least one percussion-free breakdown [S9] |
| Build-up | Raise tension toward the drop | Risers/uplifters, rushing percussion, filter opening, automated delay/reverb [S7][S9] |
| Drop | Payoff: full groove returns | Brief silence before the drop (with reverb tails left running) makes it hit harder [S7]; trance usually has no EDM-style drop [S9] |
| Bridge / second theme | Contrast before the second peak | Re-combine elements, chop/pitch/reverse sections [S7][S11] |
| Deconstruction / outro | Let a DJ mix out | Mostly percussion; mirrors the intro [S5][S12] |

## 2. Transition tools

- **Risers / uplifters and fallers / downlifters** to ease section changes [S9]; rising/falling FX, **reverse
  cymbals**, automated delay/reverb throws [S7].
- **Filter sweeps:** high-pass to thin the low end just before a new section; low-pass opening through a
  breakdown [S7].
- **Kick drop:** removing kick (and bass) is the primary way to make a breakdown; returning it is the drop [S7].
- **Fills / snare rolls:** trance loop ends with a clap triplet flourish [S9]; Melbourne-bounce style uses 8-bar
  snare fills before the drop [S19].
- **Silence / gap** right before the drop, reverbs still ringing [S7].
- **Printed and reversed reverb** of percussion as a swell into a section [S12].

## 3. Phrase lengths and DJ structure

- Dance tracks are organised in **16-bar blocks**; individual loops repeat in 1-, 2-, 4- or 8-bar phrases; change
  something (add, remove, alter) **every 4 or 8 bars** [S7]. Techno guide: something new or something removed
  about every 16 bars [S5]; tech-house example changes elements every 8 bars [S14].
- Phrases of 4, 8 or 16 bars typically begin with a new melody or rhythm (progressive house) [S22].
- Section boundaries therefore fall on bars **1, 17, 33, 49, 65, 81, 97, 113, 129…** (= 16n + 1) **(derived)**.
- One published club-track map (256 bars) [S7]: mini-breakdown at **bar 65**, main breakdown at **bar 129**
  (midpoint), drop into outro beats around **bar 193**; first three-quarters filled with builds and occasional
  breaks.
- **DJ-friendly intro/outro:** a beat-led intro and outro of at least 16 bars, commonly 32, is the standard
  convention **(to verify – the checked MusicRadar piece gives no bar count [S7])**; the outro should mirror the
  intro so the next track can be phrase-matched.

## 4. Energy development

- Energy is shaped by **density** (number of layers), **spectral range** (filters), **rhythmic subdivision**
  (8ths → 16ths), **level** (breakdown a few dB lower [S7]) and **register** of the hook.
- Typical curve **(convention)**: intro low → construction rising → first peak → mini-break → second peak →
  main breakdown (lowest density, highest emotion) → build (rising tension) → main drop (highest energy) →
  deconstruction falling → outro.
- Trance: predictability is the goal; long builds, intro of gradually added elements [S9].

## 5. Avoiding loop fatigue

1. **Subtractive arrangement:** build the full 8-bar loop first, duplicate it across the timeline, then *remove*
   elements to create sections [S5] ("start from a strong eight-bar loop and sculpt it").
2. **Variation every 4/8/16 bars:** add, mute, swap or alter a part (fill, new hat, bass note change) [S5][S7].
3. **Automation:** filter cutoff/resonance (acid lines especially) [S5], delay/reverb sends [S7], A/B balance of
   melody layers [S12], level of breakdowns [S7].
4. **Re-combination:** chop, pitch, stretch or reverse grouped sections [S7]; NI deep-house example recombines
   the same elements later in the track [S11].
5. **Call-and-response / note changes:** move the bass to other degrees in later bars [S8].
6. **Polymeter** to make a static loop evolve (see [README §7](README.md#7-polyrhythm-and-polymeter)) [S6].

## 6. Arrangement templates per genre (COSOUND starting points – convention, to verify)

Bar numbers are the first bar of each section. Times at the stated BPM are **(derived)** with `240/BPM` s per bar.

### Techno (≈132 BPM, 224 bars ≈ 6:47)
| Bars | Section | Content |
|---|---|---|
| 1–16 | Intro | Kick + percussion + atmosphere, no bass [S5] |
| 17–32 | Intro 2 | + hats, rumble |
| 33–64 | Construction | + rolling bass, open hats, main sequence |
| 65–80 | Mini-break | Kick out or filter-down 8–16 bars |
| 81–112 | Peak 1 | Full groove, acid/lead automation |
| 113–128 | Breakdown | Kick/bass out, atmosphere and sequence |
| 129–144 | Build/drop | Filter/riser into full return |
| 145–192 | Peak 2 | Full groove + variation every 8/16 bars |
| 193–224 | Outro | Deconstruct to percussion [S5] |

### Melodic Techno / Melodic House (≈122 BPM, 224 bars ≈ 7:21)
| Bars | Section | Content |
|---|---|---|
| 1–16 | Intro | Kick, hats, perc, pads [S8] |
| 17–32 | Groove | Full drums, bass, bass accent [S8] |
| 33–48 | Theme | Lead melody enters [S8] |
| 49–64 | Variation | Remove shaker/rim (energy dip) [S8] |
| 65–96 | Peak 1 | Full arrangement, chord layers |
| 97–128 | Breakdown | Drums out, cinematic chords + lead, long reverbs |
| 129–144 | Build | Riser, filter, snare/perc roll |
| 145–192 | Drop / Peak 2 | Full + new layer |
| 193–224 | Outro | Strip back to drums |

### Progressive House (≈126 BPM, 256 bars ≈ 8:08)

| 113–144 | Main breakdown → long main build-up |
| 145–176 | Main drop |
| 177–192 | Build-up |
| 193–224 | Drop 2 |

## 7. COSOUND rules for arrangement advice

1. Count in bars from bar 1 and place section changes on 16n + 1 unless the reference track shows otherwise.
2. When the user shares a reference, derive its section map from measured energy/novelty curves
   (see `../audio-engineering/measurement-analysis.md`) and prefer that to the templates.
3. When suggesting a change, name the tool (filter, mute, riser, kick drop, automation) and the bar range.
